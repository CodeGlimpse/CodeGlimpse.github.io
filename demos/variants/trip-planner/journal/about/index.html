一页老城漫游手记

“巷里漫游”收下栖钟院、墨线巷、拾页印房与拐角晚茶等八处虚构街巷片段。 地点名称、描述、地形与坐标全部是原创虚构设定，不能据此安排实际出行。地图折线只表示当前清单顺序，非真实地理导航，不表示道路、距离或可通行性。老城的街网、院落和河岸是原创图面。

时间与预算

每处地点有固定的示例停留分钟数，相邻两处统一增加 20 分钟交通；顺序和示意距离不影响计算。空行程为零，一处不加交通。含交通总时间超过 **480 分钟（8 小时）**时提醒减少地点或拆分日期。天气、开放时间、船班、路况与体力均未进入计算。

费用以整数分保存并相加，再显示人民币金额；只是虚构体验或停留费用。清单之外的交通、住宿与个人消费没有计入，没有真实报价或预约服务。

怎样编排

按自然、人文、休憩筛选八处地点，最多加入六处，每处一次。上移、下移、移除或清空会同步更新地图编号、连线和汇总，筛选保留已选行程。使用 Tab 找到按钮，再按 Enter 或空格操作；重排后焦点跟随同一地点，移除后转向邻近地点。

地点便签可以展开阅读，行程中的每站手记在重排时保留展开状态，移除后清除。累计分钟从零开始，加入每段 20 分钟交通；它是相对时长，不是到达时刻。关闭 JavaScript 时便签全部展开。

数据只留在当前页面

没有后端、定位、预约、外部请求或持久化，也不读取 localStorage / sessionStorage。刷新页面、切换场景即重置行程。关闭 JavaScript 时可只读浏览八个地点与基础地图，编排控件保持禁用。演示交互不表示真实服务或客户交付。
