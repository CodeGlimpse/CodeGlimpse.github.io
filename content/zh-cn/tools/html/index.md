HTML 实体可以安全表示标签符号、引号和部分不可直接输入的字符。本工具仅在文本框中显示结果，不会将输入作为 HTML 执行。

{{< tool id="html" >}}

### 支持范围

- 编码 `&`、`<`、`>`、双引号和单引号。
- 可选将所有非 ASCII 字符编码为十六进制数字实体。
- 解码数字实体以及 `amp`、`lt`、`gt`、`quot`、`nbsp`、`copy` 等常用命名实体。

未知的命名实体会原样保留。该工具用于文本转换，不能替代服务端的上下文相关 HTML 转义和内容安全策略。
