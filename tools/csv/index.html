CSV 与 JSON 转换工具

在浏览器本地进行 CSV 与 JSON 数组双向转换。

Aug 17, 2026
阅读时长: 1 分钟
English

将带标题行的 CSV 转换为 JSON 对象数组，或将 JSON 对象数组和二维数组转换为 CSV。所有数据都在浏览器本地处理。

加载中...

示例与限制

输入 name,age\nAlice,30 会转换为包含 name 和 age 字段的 JSON 数组。支持引号字段和字段内换行，但标题必须非空且不重复；超大文件可能受浏览器内存限制。内容不会离开浏览器。

使用说明

选择转换方向和分隔符，粘贴内容后执行转换；结果可以使用工具面板中的复制、分享和本地导出操作。

格式支持

  • 支持逗号、分号、Tab 和竖线分隔符。
  • 支持引号字段、双引号转义以及字段内换行。
  • CSV 标题名称必须非空且不能重复。
  • JSON 根节点必须是数组，数组项需全部为对象或全部为数组。

大型数据集仍可能占用较多浏览器内存，建议先在副本上处理重要数据。
