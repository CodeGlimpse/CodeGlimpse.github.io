# 游戏栏目方案

当前方案已按用户的新要求实施：游戏直接运行在页面中，不使用 iframe，也不提供存档。

首批为记忆翻牌、贪吃蛇和 2048，均有中英文页面，支持桌面和手机操作。游戏代码只在点击开始后加载，分数和进度只留在当前页面内存，刷新后重置。

第二批已按用户“全部加入”的要求实现扫雷、打砖块、打地鼠、关灯游戏、数字滑块、点按飞行和四子棋，栏目合计十款。四子棋采用共用设备的本地双人玩法；两款逻辑拼图生成可解局面。全部沿用中英文页面、局部输入、暂停、重开和无存档约定。

第三批（2026-09-08）加入目录搜索，以及方块堆叠、推箱子、井字棋人机对战、迷你数独、反应测试和记忆序列，合计十六款。搜索匹配双语名称、别名和玩法关键词，保留全部静态卡片作为无脚本回退；游戏继续在点击开始后加载。

原先关于 iframe、独立来源和本地存档的建议已被明确要求取代。当前架构、代码位置、资源预算、验证结果及新增游戏的约定以 [游戏维护文档](games.md) 为准。

最初的可行性讨论可从本文件的 Git 历史查看，不作为当前实现要求。
