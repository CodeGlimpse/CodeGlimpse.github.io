XML 工具可以整理配置和接口数据，并在浏览器本地检查标签是否匹配。

{{< tool id="xml" >}}

### 示例与限制

输入包含唯一根元素的 XML，选择格式化、压缩或校验。工具不会解析外部实体，也不会执行输入内容。

### 使用说明

- 格式化会按两格缩进输出。
- 压缩会移除标签之间多余空白。
- 语法错误会显示不匹配或未闭合的标签。
