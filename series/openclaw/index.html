OpenClaw 使用与维护

按安装、浏览器使用、排障、卸载的顺序阅读 OpenClaw 教程。

English

这组四篇文章覆盖一次本地使用流程。先了解安装要求，再选择浏览器连接方式，遇到问题按环节排查，最后学习卸载与清理。

  1. 安装与配置：检查 Node.js 和包管理器版本，完成初始化，再验证 Gateway。

  2. 浏览器连接模式：区分托管浏览器、Chrome DevTools MCP 和 Chrome 扩展。

  3. 分层排障：区分运行时、Gateway、模型请求和浏览器连接的问题。

  4. 卸载与清理：先预览清理范围，分别处理服务、状态、工作区和 CLI。

配置中的普通 JSON 示例可以在 JSON 工具 中练习；比较两份示例配置时可使用 文本 Diff。OpenClaw 的完整配置可能使用 JSON5，JSON 工具不能替代 OpenClaw 自身的配置诊断。
