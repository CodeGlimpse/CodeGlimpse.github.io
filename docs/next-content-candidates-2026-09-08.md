## A 批：三篇实战文章

### A1. Windows 下 python、py、pip 指向不同环境怎么办

- 从“安装成功但找不到命令”“pip 装了包仍无法导入”“进入虚拟环境后版本不对”三个现象展开。
- 解释命令路径、解释器路径、`python -m pip`、虚拟环境，以及新旧 Python 启动方式之间的区别。
- 使用实际环境的命令输出和截图，给出每步应观察的结果与恢复方式；链接回现有 Python 安装教程。
- 交付：中英文文章、必要截图、可复制命令。没有实际验证的环境不写成已测试结论。

### A2. OpenClaw 装好了却用不了：从现象定位问题

- 区分 CLI 可用、Gateway 运行、模型请求成功和浏览器连接成功四个环节。
- 选择能在实际环境复现的问题，例如命令路径不一致、服务未运行或浏览器模式选错；说明现象、定位依据和解决步骤。
- 普通 JSON 片段可链接本站 JSON/Diff 工具；不把 JSON5 配置误当成普通 JSON。
- 交付：中英文文章与经过脱敏的实际输出，接入现有文章内导航，不增加独立系列入口。

### A3. 反应测试为什么会多算几十毫秒

- 用本站修正过的例子解释鼠标按下、松开和 `click` 的时间差。
- 解释输入事件时间戳、浏览器绘制帧、抢跑、暂停和重新开始对计时的影响。
- 展示“230 ms 按下、80 ms 后松开”这一可控示例，说明固定减去一个数值为什么不是合理校准。
- 交付：中英文技术文章、少量代码与时序图，链接到本站反应测试。文章讲实现原理，内部审查记录留在仓库。

建议从 A1 和 A3 开始，分别承接现有教程和游戏。

## B 批：两个本地工具

### B1. 二维码生成与解析

- 输入文本或网址生成二维码；支持尺寸、纠错等级和 PNG 下载。
- 选择本地二维码图片进行解析，并允许复制识别内容。
- 识别出的网址只展示，不自动打开；第一版不调用摄像头。
- 计算在浏览器内完成。实施前单独确认解码库及许可证，将依赖打包到本站。
- 验证：中文、Emoji、长文本、不同纠错等级、无法识别的图片、手机操作和无网络环境。

### B2. 图片压缩与尺寸调整

- 第一版处理单张图片，支持等比例缩放、质量调节，以及 JPEG/WebP 输出。
- 展示原图与结果的尺寸、体积，允许下载处理结果；透明图片转 JPEG 前明确背景颜色。
- 明确动态图片与元数据处理范围；采用输入体积、像素总量限制控制浏览器内存使用。
- 验证：手机照片方向、透明背景、大图边界、质量滑块、格式兼容和离线使用。

## C 批：三款无需存档的游戏

### C1. 舒尔特方格

- 5×5 方格随机排列 1–25，按顺序点完后显示本局用时和误点次数。
- 支持重新开始、暂停和键盘操作；只保留本局状态。
- 验证：顺序判定、误点、暂停计时、窗口失焦和手机触控。

### C2. 连连看

- 点击两个相同图案，用不超过两次转弯的连线消除；以清空棋盘为目标。
- 提供提示与重排；无可用配对时保证能够继续游戏。
- 使用本站自制图形或可明确授权的图案，适配手机点击。
- 验证：棋盘边缘连线、阻挡、死局、重排后可解及单局重置。

### C3. 本地双人五子棋

- 两人在同一页面轮流落子，先连成五子获胜；第一版使用自由规则，不含禁手或电脑对手。
- 显示当前执子方、胜线、平局和重新开始操作。
- 验证：四个方向的连线、边缘落子、重复点击、结束后锁定、手机棋盘操作。

三款均直接使用 DOM/Canvas 在页面运行，不使用 iframe，不增加账号、联网对战或持久化成绩。建议先 C1，再 C2，最后 C3。
