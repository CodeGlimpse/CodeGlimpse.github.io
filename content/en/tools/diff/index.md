The text Diff tool is useful for comparing code, configuration, and documents. Results are generated locally in the browser.

{{< tool id="diff" >}}

### Examples and limits

Enter two text blocks and choose Compare. The tool compares lines, supports up to 2500 lines per side, and can ignore whitespace or case.

### Usage

- Added lines are highlighted in green and removed lines in red.
- Copy or download the comparison as a text report.
- Input is never uploaded.
