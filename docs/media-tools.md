# 二维码与图片工具

- 页面：`/tools/qrcode/`、`/tools/image/` 及对应英文页；共 24 个工具。
- 依赖固定为 qrcode-generator 2.0.4（MIT）和 jsQR 1.4.0（Apache-2.0），许可证全文在 `static/licenses.txt`。两个库只打包到专用 Worker，不使用第三方 CDN。
- 二维码任务 6 秒超时后终止，清空或修改输入取消旧任务。内容最多 2000 UTF-8 字节，拒绝无效代理项，支持中文和 Emoji；使用整数像素和白边绘制 PNG。
- 图片先检查文件头、20 MiB 体积、8192 单边与 1600 万像素上限，再解码；接受静态 PNG/JPEG/WebP，拒绝动画、SVG、GIF 和异常文件。
- 图片输出保持比例、不放大、最长边 4096；Canvas 按解码方向重编码，JPEG 填充选定背景，WebP 保留透明区域，不复制原 EXIF。结果变大时如实显示。
- 两个工具不提供输入分享链接或 JSON 快照。图片、文件名和识别内容不写入 URL、存储或自定义统计事件；工具区域有 Clarity 屏蔽标记，未在本批检查第三方后台设置。
- 对象 URL、ImageBitmap 和临时 Canvas 按生命周期释放。文件加载和结果采用独立版本控制，参数变更不会误取消文件加载；旧结果不能覆盖新选择。
- 单元用例覆盖文件边界、比例及 QR 回读。浏览器用例检查 PNG 下载回读、JPEG/WebP 像素、EXIF 方向、透明背景、离线、窄屏、取消与超时。
