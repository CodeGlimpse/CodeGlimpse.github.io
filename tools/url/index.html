URL 编码/解码工具

在线 URL 组件编码与解码工具，支持 Unicode 和表单空格模式。

Aug 17, 2026
阅读时长: 1 分钟
English

URL 编码可以将空格、中文和保留字符转换为适合放入网址参数的百分号转义形式。本工具在浏览器本地处理输入，不会上传内容。

使用说明

  • 编码：将普通文本转换为 URL 组件格式。
  • 解码：将 %E4%BD%A0 等百分号转义还原为文本。
  • 表单模式：启用后，编码时将空格转换为 +，解码时将 + 视为空格。

编码结果适用于单个路径片段或查询参数值。完整网址中的 /、?、& 等结构字符应按实际结构分别处理。
