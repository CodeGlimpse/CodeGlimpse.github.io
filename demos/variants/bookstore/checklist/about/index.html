周末书单 / 2026 第 45 周。这是一间虚构书店，十二本图书分为料理、居家、自然，每类四本。书名、作者、简介、价格和库存均为本演示原创示例，不对应真实出版物、商家或客户。封面由本地 CSS 与原创 SVG 绘制，页面使用本机字体。

怎么翻阅

生活书目按清单排列，简介可独立展开；行内加减数量和常驻小票使用同一购物袋状态。 搜索只匹配书名，多个关键词需要同时出现在书名中；全角与半角字符会统一，中文输入结束后更新。筛选不会清空购物袋。

购物袋里的金额与数量

单价以整数分记录，小计按单价乘数量后相加，显示两位小数的人民币金额；小计仅表示图书价格合计。示例库存为 0—9 本，库存为零时显示售罄。数量不能超过库存，减至零或移除会删除该条目。清空购物袋会清除全部临时选择。

虚构演示 · 模拟购物袋

购物袋只在当前页面内存中保存，刷新、离开或切换场景即重置。没有结算、下单、支付、账户、后台和个人信息收集，不会产生真实交易。页面不读写浏览器持久化存储，也不请求外部数据。

关闭 JavaScript 后，十二本书的书名、简介、单价和库存仍可阅读；分类、搜索与购物袋控件保持不可用。所有场景均提供各自独立书目，菜单会进入对应场景首页。
