项目案例 / 信息设计

雨迹记录卡

一套虚构的自然观察记录卡，探索雨量信息的视觉层级。

CLASS
信息设计
COLLECTION
项目案例

项目背景

这是为演示作品集结构而创作的虚构命题：让一次雨天观察可以被简洁地记录、回看和分享，不对应任何真实机构或客户。

设计思路

信息从日期、天气到观察笔记逐层展开。圆形波纹表示时间的延伸，线条与留白帮助阅读者区分主要记录和辅助说明。

展示内容

本案例展示了封面、记录区和图形元素如何在同一视觉系统中配合。所有图片和描述均为原创虚构演示。
