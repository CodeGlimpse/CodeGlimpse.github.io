JSON 格式化工具可以帮助你快速整理和检查 JSON 数据，也支持将 JSON 文本转义为适合嵌入字符串的形式，或将转义后的文本恢复为原始内容。

{{< tool id="json" >}}

### 使用说明

- **格式化**：校验 JSON 并按照所选缩进输出易读的多行格式。
- **压缩**：移除空格和换行，输出紧凑的 JSON。
- **校验**：只检查 JSON 是否有效，不改变输出内容。
- **转义**：转义双引号、反斜杠和控制字符，适合将 JSON 嵌入另一个 JSON 字符串。
- **反转义**：将转义后的文本恢复为原始 JSON 文本。

工具在浏览器本地处理数据，不会上传你的 JSON 内容。
