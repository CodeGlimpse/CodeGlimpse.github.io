The YAML and JSON converter helps organize configuration files and API examples without sending data away from the browser.

{{< tool id="yaml" >}}

### Examples and limits

Common mappings, arrays, strings, numbers, booleans, and null values are supported. Anchors, tags, and multi-document YAML are not supported.

### Usage

- YAML to JSON produces indented JSON.
- JSON to YAML preserves object and array structure.
- Parsing is performed locally in the browser.
