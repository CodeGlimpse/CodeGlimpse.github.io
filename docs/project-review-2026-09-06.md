## 剩余限制和未验证事项

1. **发布尚待授权。** 本地提交和测试已完成，尚无本轮 GitHub Actions Run。推送后需确认 Build、E2E、Deploy、线上检查均通过。
2. **真实统计 SDK 的采集边界仍需单独验证。** E2E 用空脚本替代供应商脚本，验证了本站加载控制、URL 处理和脱敏标记；不能据此确认真实 SDK 的全部网络行为或 Clarity 后台设置。后续应用虚构测试数据抓包核对。
3. **完全禁用存储时，退出选择不能跨页面保存。** 当前页面会发出供应商支持的退出信号，但不能保证所有已加载 SDK 停止收集。这个限制已写入双语隐私页；如要更强保证，需要另外决定统计加载策略。
4. **工具有明确格式边界。** SQL 为轻量格式化工具，不能替代数据库方言校验；YAML 拒绝锚点、别名、显式标签、多文档、非字符串键和不安全数值；XML 不进行 DTD/XSD 校验。页面已披露相应限制。
5. **覆盖范围仍有限。** 本轮浏览器验证针对 Chromium，未安装或测试 Firefox/WebKit；旧教程的最新上游版本与所有外链也未逐一实机复核。暂未对超大文本做专门性能基准。

以上是剩余工作和能力边界，不应表述成“全站已无任何问题”。本轮已验证的六个原始复现均已通过回归检查。
