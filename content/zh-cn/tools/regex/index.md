使用 JavaScript 正则表达式检查匹配位置、捕获组和替换预览。表达式在独立 Worker 中执行，超过时间限制会自动终止，避免阻塞页面。

{{< tool id="regex" >}}

### 示例与限制
模式 `(\\w+)=(\\d+)` 处理 `a=1`，替换 `$1:[$2]` 后得到 `a:[1]`。使用 JavaScript 正则语法；输入、模式和结果数量均有限制，Worker 超时会终止执行。测试文本不会上传。

### 支持的标志

- `g` 全局匹配
- `i` 忽略大小写
- `m` 多行模式
- `s` 允许点号匹配换行
- `u` Unicode 模式
- `y` 粘连匹配

工具限制表达式、测试文本和匹配结果数量。超时保护可以降低页面卡死风险，但生产系统仍应避免接收未经约束的复杂正则表达式。
