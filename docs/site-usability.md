# 栏目搜索与页面体验

## 页面与入口

- 博客搜索位于 `/archives/`，英文版为 `/en/archives/`。搜索数据由对应页面的 `index.json` 输出，范围仅为已发布文章的标题、摘要、标签与正文。
- `/search/`、`/en/search/` 及两个旧搜索 JSON 地址已删除，预期返回 404，不提供重定向。侧栏和首页搜索挂件同步移除。
- 工具、游戏目录保留各自的搜索。三类搜索支持全角字符、多个关键词、输入法组合输入、清空、Escape 和无结果提示。关闭 JavaScript 时仍可浏览完整目录。
- 手机首页提供固定底栏，分别进入文章、工具和游戏；桌面端及其他页面不显示该底栏。底栏为安全区和隐私提示预留位置。
- 手机顶部使用较小头像、横向简介和较紧凑的间距。没有为首页卡片或文章顶部新增更新日期。

## 工具与阅读

- JSON 格式化和压缩首先验证语法，再排版词法记号；不将 `JSON.parse` 得到的数字重新序列化。长整数、小数、指数、负零、键顺序、重复键和字符串转义均保留原样。
- 工具详情省略阅读时长和发布日期，提供可退出的专注模式。切换只改变布局，不重建工具，不清空输入，也不保存输入。
- 文章小标题旁的 `#` 按钮复制段落地址。复制失败时给出页面内反馈，兼容现有剪贴板回退。
- 相关文章只推荐同标签文章，并排除已在当前系列导航中展示的内容；文章内前后篇导航继续使用原顺序。
- 主标题与列表标题通过显式模板参数区分，避免并行构建时共享页面临时状态导致首页标题失去链接。
- 游戏目录提供益智、街机、反应、记忆、双人筛选。“随机玩一款”只从当前筛选结果中选择，无结果时禁用。

## 缓存与维护

- Service Worker 更新到 `codeglimpse-v5`，使用新的博客搜索地址预缓存，并在激活时删除本站旧版本缓存。
- 配色初始化与切换允许浏览器存储读取/写入失败；当前页面仍可切换配色，游戏不会被存储异常中断。
- 发布检查要求旧搜索地址返回 404，同时验证博客页与新索引。构建产物检查支持通过 `SITE_ROOT` 指定隔离输出目录。
- Clarity 项目控制台应保持屏蔽输入和敏感文本的配置；这是维护者的后台检查事项。本次未读取或更改后台设置。公开隐私说明保留数据处理行为与用户退出方式，不包含后台操作要求。
- 关于页补充游戏入口，联系方式采用本站用途说明，MD5/SHA 使用哈希和摘要术语，并区分数据摘要与密码存储方案。

## 验证入口

- `npm.cmd test`、各项 `check:*` 静态检查及 Hugo 构建。
- `e2e/site-usability.spec.cjs`：栏目范围、搜索交互、删除地址、手机底栏、专注模式、数字精度、段落链接及失败回退。
- `e2e/game-catalog.spec.cjs`、`e2e/reading.spec.cjs`、`e2e/tools.spec.cjs`：已有搜索、键盘、离线和阅读功能的回归覆盖。
- 浏览器验证使用现有 Chromium。手机尺寸模拟不等于真实 iOS Safari 验证。
