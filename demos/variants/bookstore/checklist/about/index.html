一间虚构的书店

“纸间书店”是一个独立的静态网页演示。十二本书的书名、作者和简介均为本演示虚构创作，不对应真实出版物、真实客户或销售案例。封面由本地 CSS 绘制，不使用外部图片或字体。

翻一翻，也试一试

你可以按文学、设计、生活筛选书目，也可以输入书名中的关键词。多个关键词之间用空格分开，书名需要同时包含这些词才会显示；搜索会统一全角与半角字符，并在中文输入完成后更新。

加入模拟购物袋后，可以增加或减少数量、移除一本书，或清空整个购物袋。数量减至零会移除该书。筛选书目不会改变购物袋中的内容。

金额与库存

每本书的单价以整数“分”记录，商品小计按单价乘数量后相加，最后展示为两位小数的人民币金额。小计只表示演示图书价格合计，不包含运费或其他费用。

示例库存为 0—9 本。库存为零时显示“售罄”，购物袋中每本书的数量不能超过其示例库存。这些库存不是实时商品数据，也不会因其他访客的操作发生变化。

本次浏览，恰好足够

购物袋只保存在当前页面的内存中。刷新页面或离开页面后，购物袋会重置；页面不使用浏览器持久化存储，也不请求远程数据。

这是“虚构演示 · 模拟购物袋”，没有结算、下单、支付、账户或个人信息收集功能，不会产生真实订单。关闭 JavaScript 后，完整书目、单价和库存仍然可读，筛选与购物袋控件保持不可用。
