双人五子棋

黑白双方轮流落子，抢先连成五子。

English
步数 0 轮到 黑方

准备好了就开始吧。

点击上方按钮，开始一局

刷新页面会重置本局。

怎么玩

两人在同一页面轮流操作，黑方先手。在 15×15 棋盘上，横、竖或斜线连续五子即可获胜；使用自由规则，不设禁手，超过五子的连线也算获胜。棋盘填满且无人获胜时为平局。

先点选一个位置，再点“落子”。手机上可用下方方向按钮微调位置；电脑也可以双击位置落子，或用方向键选择后按回车、空格确认。已有棋子的交叉点不能重复落子。

最后一手和胜利连线会被标出。棋盘内按 P 或 Esc 暂停、继续；点击游戏外部或切换窗口会自动暂停。重新开始清空棋盘，双方重新轮流落子。
