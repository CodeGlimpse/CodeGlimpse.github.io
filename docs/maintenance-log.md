## 初始维护基线

- 类型：维护机制
- 影响范围：本地检查、PR 发布、主题更新和线上监控流程
- 变更内容：建立长期维护手册、发布摘要、完整线上巡检和每周监控
- 验证命令：`npm.cmd run check`、`npm.cmd run test:e2e`、线上 `check:site`
- 验证结果：以本次维护提交和发布工作流结果为准
- 源代码提交：见 Git 历史
- GitHub Actions Run：见仓库 Actions
- 回滚：无
- 后续事项：定期复核版本、主题和线上资源
