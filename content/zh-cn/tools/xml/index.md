XML 工具可以整理配置和接口数据，并在浏览器本地检查 XML 语法。

### 示例与限制

输入包含唯一根元素的 XML，选择格式化、压缩或校验。工具会拒绝 DOCTYPE 声明，不加载外部实体，也不执行输入内容。校验仅检查 XML 语法，不进行 DTD 或 XML Schema 校验。

### 使用说明

- 格式化只调整元素容器之间的缩进，默认使用两格空格。
- 压缩只移除元素容器中的排版空白，保留混合文本、CDATA、纯文本节点和 `xml:space="preserve"` 区域。
- 输出可能统一属性引号和空元素写法；数据语义保持不变，原始字节排版不保证一致。
- 未闭合标签、缺少属性引号、重复属性等语法错误会显示原因。
