The XML tool organizes configuration and interface data while checking matching tags locally in the browser.

{{< tool id="xml" >}}

### Examples and limits

Enter XML with one root element and choose Format, Minify, or Validate. External entities are not parsed and input is never executed.

### Usage

- Format output uses two-space indentation.
- Minify removes unnecessary whitespace between tags.
- Syntax errors report mismatched or unclosed tags.
