The Markdown preview supports headings, paragraphs, lists, links, emphasis, and code blocks while filtering raw HTML.

{{< tool id="markdown" >}}

### Examples and limits

Common Markdown syntax is supported. Scripts and event attributes are not executed. Preview and HTML generation happen locally in the browser.

### Usage

- Preview updates as you type.
- Load an example, copy HTML, or download an HTML file.
- Extended Markdown features such as tables and footnotes are not supported.
