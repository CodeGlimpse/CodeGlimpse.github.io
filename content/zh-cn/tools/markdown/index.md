Markdown 预览工具支持标题、段落、列表、链接、强调和代码块，并会过滤原始 HTML。

{{< tool id="markdown" >}}

### 示例与限制

支持常用 Markdown 语法，不执行输入中的脚本或事件属性。预览和 HTML 生成完全在浏览器本地完成。

### 使用说明

- 输入内容会实时显示在右侧预览区。
- 可以加载示例、复制 HTML 或下载 HTML 文件。
- 不支持扩展 Markdown、表格和脚注语法。
